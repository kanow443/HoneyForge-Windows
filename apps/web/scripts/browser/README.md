# Real HoneyForge browser acceptance

Run from apps/web. These scripts launch their own isolated headless Playwright Chromium and authenticate to the actual API through the frontend proxy. They do not operate the user's browser, mock responses, fabricate events or save authenticated browser state. Administrator credentials are read silently from the private repository .env; never pass them in a recorded command. Install Chromium using npx playwright install chromium if it is absent.

Latency means Date.now at first visible row-layout intersection minus the event's real observed_at, using the shared machine clock. It is not HTTP ingestion latency, SSE receipt time or a browser paint timestamp; paint can add a frame. The observer excludes preexisting timestamps, deduplicates each path, preserves first sightings across navigation, records unpaired/unseen paths and API/parse errors, and computes p95 for paired displayed rows. The bounded latest-event table does not display every event under load; absent rows are not silently included in the percentile. A passed browser percentile is conditional on this displayed sample and does not imply zero loss or whole backend acceptance. Full accepted/unique/dropped counts and SSH stability belong to backend scale.json.
