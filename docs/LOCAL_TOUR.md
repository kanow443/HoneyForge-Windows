# HoneyForge: быстрый локальный проход

Обновлено 10 октября 2026 года. Полная инструкция по всем экранам, кнопкам, полям, состояниям и действиям фронтенда/бэкенда находится в [USER_GUIDE_RU.md](USER_GUIDE_RU.md). Здесь короткий маршрут для уже установленного стенда. Установка: [DEPLOYMENT.md](DEPLOYMENT.md).

1. Открой `http://localhost:5173`, войди учётной записью из `.runtime/access.txt` (Finder → Cmd+Shift+G → `/Users/admin/Documents/GitHub/hack/.runtime`).
2. «Хосты»: проверь неотозванный сенсор `192.168.139.142`, свежий heartbeat, HTTP/SSH и очередь. Отзыв хоста не нужен для демонстрации.
3. «Развёртывания»: убедись, что `Finance intranet · LIVE` на 18080, `Operations bastion · LIVE` на 2222 и `File staging · LIVE` на 18081 работают. Если не подготовлены: из корня `uv run python scripts/prepare-demo.py`.
4. Открой `http://192.168.139.142:18080`, пробуй вход только синтетическими данными и файл `/opt/decoy/backup-notes.txt`. Это реальные запросы к VM.
5. Открой «Сеть ловушек», выбери источник/ловушку на карте. «Сессии» → «Открыть плеер»; либо «События» → открыть запись → «Разобрать сессию».
6. В терминале подключись к SSH-приманке:

```sh
ssh -p 2222 -o UserKnownHostsFile=/tmp/honeyforge-demo-known_hosts root@192.168.139.142
```

Учебный пароль ловушки: `hackathon-demo`. Он отличается от пароля панели. Выполни `whoami`, `hostname`, `uname -a`, `cat /home/admin/backup-notes.txt`. Это эмуляция Cowrie; настоящая ОС клиента неизвестна.

7. Открой новую SSH-сессию в плеере. Команды и сохранённый вывод нового runtime появятся в истории. Поставь просмотр на паузу, введи ещё команду, вернись в LIVE. Проверь replay, ×2 и evidence правила. «К срабатываниям» возвращает список правил.
8. «Ограничить источник» → «Заблокировать источник»: срок одна минута, причина, «Запросить ограничение». Дождись «Подтверждено агентом». Новое SSH-подключение должно блокироваться; старое остаётся открытым. HTTP на 18080 с того же ноутбука должен работать. Отмени правило или дождись TTL и подтверждения снятия.
9. «Дело и контекст» → «Создать дело», заметка. В «Делах» измени состояние на «В работе» и сохрани. Сессия остаётся доступна.
10. «Отчёт»: версия приманки, события, evidence, ограничения и hash. «JSON» скачивает документ; «Печать / PDF» открывает диалог браузера.
11. Для собственного профиля: «Профили» → «Создать профиль». Текущий конструктор содержит «Сервис», «Файлы», «Ресурсы» и предпросмотр справа. «Опубликовать» → проверка → «Опубликовать версию». Затем «Развернуть v1» на свободном порту 1024–65535.
12. Новая версия профиля не меняет текущую ловушку сама. В её карточке выбери версию → «Применить повторно». Старые сессии сохраняют прежнюю конфигурацию. «Остановить» → «Остановить ловушку» требует результата агента; история сохраняется.

Если нет событий: проверь endpoint VM, паузу, фильтры и очередь. Если `unknown`, это отсутствие свежего подтверждения, не доказательство остановки. Полная таблица ошибок и восстановления — раздел 20 полного руководства. Остановленные тестовые ловушки и отозванный старый хост сохраняются в истории намеренно.
