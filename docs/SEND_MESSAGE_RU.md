Кидаю обновлённый HoneyForge — проект для хакатона и комплект запуска под Windows. Внутри исходники, установочные скрипты, Geo/ASN базы, инструкции, презентация и подготовка к защите. Нейросетей внутри приложения нет.

Для локального демо облако и отдельный сервер не нужны. Центр работает в Docker Desktop на Windows, ловушки — в отдельной Ubuntu 24.04 VM на том же компьютере. Интернет нужен при первой установке и сборке.

**Как запускать**

1. Распакуй `HoneyForge-Windows-2026.10.11.zip` в `C:\HoneyForge` и открой папку `HoneyForge-Windows`. Из самого ZIP ничего не запускай.
2. Сначала открой `README_WINDOWS.md`: там пошагово расписаны подготовка Windows, создание Ubuntu VM, сеть, регистрация сенсора и демо. Рекомендуется Windows 11, 16 GB RAM и включённая виртуализация.
3. Если Docker Desktop ещё нет, запусти `INSTALL_PREREQUISITES.cmd` от администратора. После установки открой Docker Desktop и дождись `Engine running` с Linux containers.
4. Создай Ubuntu VM и настрой сеть по разделу 3 руководства. Затем запусти центр через `START_WINDOWS.cmd`, указав доступный сенсору IP Windows по инструкции. При нескольких сетевых интерфейсах этот шаг выполняется из PowerShell с параметром `-ManagementAddress`.
5. Панель откроется на **https://localhost:8443**. Логин и случайный пароль находятся в `.runtime\windows\access.txt`, который появится после настройки. Этот файл никому не пересылай.
6. Установи сенсор по разделу 4: на VM копируются `sensor-source.zip` и публичный сертификат, затем сенсор регистрируется токеном из раздела «Хосты». В панели должен появиться хост Online.
7. Для подготовки демо выполни из PowerShell в папке комплекта: `.\START_WINDOWS.cmd -Action Demo -SensorAddress 192.168.56.101`. **IP здесь пример — замени на адрес своей Ubuntu VM.** Дождись Running у ловушек. Как подключаться по SSH/HTTP и показывать плеер, файл и реакцию — разделы 5–6 руководства.

В конструкторе уже можно объединять 2–8 сервисов и портов в одном профиле. Geo/ASN базы включены; для частных IP география честно отображается как недоступная. Для основного трёхминутного демо используй Low и Medium. High показывай отдельно с заранее открытой сессией: для него Ubuntu-сенсору рекомендуется 4 CPU и 8 GB RAM, настройка описана в отдельном гайде.

Бэкенд и фронтенд прошли 82 и 139 тестов. Реальная ОС, сброс и SFTP проверены на QEMU TCG. Нативный Windows и ускорение KVM нужно проверить на вашем компьютере по инструкции.
