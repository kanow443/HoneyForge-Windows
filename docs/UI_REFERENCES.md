# Интерфейс HoneyForge и референсы Mobbin

Панель помогает оператору ответить на три вопроса: какие ловушки работают, что наблюдалось и какое действие доступно. Основной путь — создать профиль, применить его на хосте, открыть живые события и перейти к сессии. Реальные данные и ясные ошибки важнее количества декоративных графиков.

Обновление 10 октября: текущая реализация конструктора описана ниже. Новые референсы плеера, схемы сети и ограничений источника, а также границы их будущей реализации находятся в [концепции развития](PRODUCT_CONCEPT.md).

Референсы найдены в Mobbin для web и просмотрены по изображениям. Их элементы ниже привязаны к конкретным сценариям HoneyForge. Это источники паттернов, а не готовые экраны проекта. Семь изображений сохранены локально; постоянные ссылки находятся в [manifest.json](references/manifest.json).

## Навигация и экраны

Текущее основное меню: Сеть ловушек, Развёртывания, События, Профили, Хосты, Журнал оператора. Сессия открывается из события или страницы ловушки. Первый экран после входа — обзор; при отсутствии данных он ведёт к подключению хоста и созданию профиля.

| Экран | Содержимое | Главное действие | Состояния, которые должны быть реализованы |
| --- | --- | --- | --- |
| Вход | Пользователь, пароль, ошибка входа | Войти | Ожидание, неверные данные, ограничение попыток |
| Обзор | Работающие ловушки, доступность хостов, события за период, очередь/потери, последние findings | Создать ловушку | Нет хостов, нет событий, offline, degraded |
| Ловушки | Таблица: имя, adapter/уровень, хост, endpoint, версия, статус, последнее событие | Развернуть | Running, Applying, Error, Stopping, Stopped, Unknown |
| Детали ловушки | Endpoint, версия/digest, фактическое состояние, этапы, логи, связанные события | Остановить или повторить отказавшее задание | Конфликт порта, timeout, host offline, старый heartbeat |
| Профили | Шаблоны и пользовательские версии | Создать профиль | Пустой список, версия без deployment |
| Конструктор | Шаблон, легенда, поддерживаемые параметры, фиктивные ресурсы, preview, итог | Опубликовать версию | Ошибки полей, несовместимость adapter, несохранённые изменения |
| Выбор развёртывания | Версия профиля, compatible host, порт, итоговые параметры | Развернуть | Нет подходящего хоста, занятый порт, API отказ |
| Хосты | Имя, адрес, capabilities, heartbeat, ресурсы, очередь, runtime version | Подключить хост | Enrollment token истёк, revoked, offline |
| События | Поиск, фильтры, histogram, live indicator, таблица, details справа | Открыть сессию | Loading, нет данных, reconnecting, paused, stream reset |
| Сессия | Источник, версия профиля, последовательность, команды, findings и evidence | Экспорт JSON | Активная сессия, неполный сбор, truncation, завершённая |
| Audit | Оператор, действие, объект, время, результат | Открыть объект | Нет записей, недоступный объект с сохранённой историей |

URL сохраняет фильтры, выбранный период и объект, чтобы можно было вернуться к расследованию. Конкретные маршруты определить в T01. Формы профиля и развёртывания различаются: изменение легенды создаёт версию, выбор хоста создаёт runtime.

## Конструктор

Текущая реализация использует две панели: конфигурация и интерактивный локальный preview. Разделы конфигурации — сервис, файлы и ресурсы; дополнительные настройки свёрнуты. Редактор CodeMirror поддерживает поиск, замену, подсветку JSON, undo/redo и расширение на рабочую область. Перед публикацией пользователь проверяет итог. Черновик восстанавливается в текущей вкладке браузера.

Слева форма, справа — имя, adapter/уровень, preview и ограничения. Неактивные поля объясняют причину. Ошибки API привязываются к полям. Опубликованная версия содержит config hash и номер; изменение существующего профиля ведёт к следующей версии.

Пример синтетической легенды: `files-stage-02`, служебный портал «Asset Console», SSH-окружение с фиктивным `backup-notes.txt`. Конкретные баннеры должны быть согласованы с возможностями T02. Любой preview отображает недоверенное содержимое как текст или в изолированной области без доступа к панели.

## События и сессия

```text
События                  За 15 минут     Поток подключён
[Поиск] [Хост] [Ловушка] [Протокол] [Тип] [Пауза]
[Количество событий за тот же период]
Время       Источник       Ловушка       Тип        Кратко
23:10:02    10.10.0.12     ssh-stage     command    uname ...
23:10:01    10.10.0.12     ssh-stage     login      вход принят
                                      | Подробности события
                                      | Наблюдалось / Получено
                                      | Источник и версия
                                      | Payload как текст
                                      | Открыть сессию
```

Новые записи не двигают выбранную строку. Если оператор прокрутил историю, показывается кнопка «12 новых событий». Пауза останавливает обновление отображения, а не сбор агентом. На экране различаются «поток подключён» и «источник доступен»: SSE может работать при offline sensor.

В сессии команды показываются последовательностью с временем и результатом наблюдения. Источник, session ID и runtime generation доступны в деталях. ANSI очищается. По клику на finding подсвечиваются конкретные события, участвующие в правиле. Количество событий и границы времени совпадают с экспортируемой выборкой.

## Визуальная система

Предлагаемая тема — графитовые поверхности с янтарным акцентом HoneyForge. Паттерны компоновки из светлых референсов сохраняются; цвета адаптируются к собственной теме. Для одного исполнителя достаточно одной завершённой темы.

| Токен | Стартовое значение | Назначение |
| --- | --- | --- |
| background | #111318 | Основной фон |
| surface | #1A1E26 | Карточки и панель подробностей |
| border | #343B48 | Видимые границы без тяжёлых теней |
| text | #F3F4F6 | Основной текст |
| text muted | #A8B1C2 | Вторичные подписи |
| accent | #F4B740 | Основное действие и выбор |
| success | #5BD6A2 | Running и подтверждённый успех |
| danger | #FF7D8B | Ошибка и критическое состояние |

Контраст проверяется в T14 для текста, текста на кнопке и статусов. Акцентная кнопка имеет тёмный текст. Ошибка обозначается текстом и иконкой, не только цветом. Findings не используют danger автоматически для каждой команды.

Основной шрифт — локальный системный sans-serif; endpoint, IDs и логи — monospace. Размеры: основной текст 14–16 px, строки таблицы 40–44 px, заголовок страницы 24–28 px, sidebar около 216 px. Модуль отступов 4/8 px. Табличные числа и timestamps выравниваются, длинные значения раскрываются в details.

Целевая ширина демо 1440 px, рабочая приёмка 1280 и 1024 px. На узком окне скрываются второстепенные колонки; подробности открываются поверх списка с понятным возвратом. Мобильный полнофункциональный интерфейс не входит в P0.

Анимации: появление detail panel около 160–200 мс, переход этапов deploy и мягкая подсветка новых событий. Учитывать reduced motion. Частые события не запускают бесконечную серию анимаций. Декоративный терминал и карта мира не требуются для объяснения работы.
